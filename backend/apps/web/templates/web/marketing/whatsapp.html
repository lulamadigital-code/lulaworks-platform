How to connect

  1. In Meta Business, create/verify your business and add WhatsApp.
  2. Add a dedicated phone number for WhatsApp Business (not one already on the WhatsApp app).
  3. Copy the Phone number ID and a permanent access token (Meta → API Setup) into the form above.
  4. Create and get message templates approved by Meta — a campaign references an approved template by name.

Uses the Meta Cloud API ({{ api_version }}). Marketing messages to a new contact must use an approved template; free text only works inside a 24-hour reply window.
